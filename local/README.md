# 交易猩猩本機版

在自己的 Windows 電腦抓期交所資料、算 v3 訊號，用瀏覽器看，功能跟 GitHub 網頁一樣（即時訊號、成交紀錄、週選、前測），
但完全不靠 GitHub，也不會自己 commit。

## 怎麼用

1. 雙擊 repo 資料夾裡的 **`啟動交易猩猩.bat`**。會跳出一個黑色視窗（伺服器），瀏覽器自動打開 http://127.0.0.1:8765/live.html 。
   - 黑色視窗開著就會自己更新；關掉視窗就停止。
   - 只有這台電腦看得到，別人連不進來。
2. 開著的時候它會自己做：
   - 交易時段（週一到週五日盤 08:45–13:45、夜盤 15:00–隔天 05:00）每 10 分鐘（可在「⚙ 設定」改成 5／15／20／30／60）重算即時訊號，網頁自動重新整理。
   - 週一到週六 06:32 收資料：期交所台指期 1 分K、台指選擇權逐筆、v3 前測。06:32 電腦沒開的話，下次打開時馬上補收。
     期交所只留 30 個交易日，所以至少每幾週要開一次，不然中間的資料會拿不到。
3. 每頁最下面有一條工具列：
   - **立即更新**：現在就重算即時訊號。
   - **收今天資料**：現在就去期交所收資料（大約半分鐘）。
   - **存到 GitHub**：把目前收集的資料 commit 並推上 GitHub 保存。只有按了才會推。建議一天最多一兩次。
     不想開網頁的話，雙擊 **`存到GitHub.bat`** 也一樣。

工具列會顯示「N 個檔案還沒存到 GitHub」，提醒你有多少資料只在本機。

## ⚙ 設定

按工具列的 **⚙ 設定** 打開設定面板，改完按「儲存設定」，馬上生效，關掉再開也會記得（存在 `local/state.json`）。

- **抓資料頻率**：交易時段每幾分鐘跑一次即時訊號（5、10、15、20、30、60 分鐘，預設 10）。最短 5 分鐘，免得太常連期交所。
- **自動上傳到 GitHub**：預設關。打開後會自己 commit 並推上 GitHub，但有三道限制：
  1. 距離上次上傳（手動或自動）至少隔你選的小時數（2、3、4、6、12、24，預設 6）。
  2. 資料真的有變才推，沒變就不 commit。
  3. 一天最多 6 次。推失敗也要等下一個間隔才再試，不會一直重推。

  原本的 txo-dashboard 就是自動 commit 太頻繁被 GitHub 停用，所以建議 6 小時以上；手動「存到 GitHub」不受影響，隨時都能按。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `local/server.py` | 本機伺服器＋排程（只用 Python 標準函式庫） |
| `local/toolbar.js` | 每頁下面的工具列 |
| `local/logs/YYYY-MM.log` | 紀錄（不會推上 GitHub） |
| `local/state.json` | 今天收過資料沒、上次存到 GitHub 的時間（不會推上 GitHub） |

網頁就是 `strategy/live.py` 等原本的程式產生在 `docs/` 的那幾頁；本機版只是不讀 Google 試算表，改看本機剛算好的結果。

## 注意

- 舊的工作排程（Tardemonkey-live-day / night）不要再打開：它每次會把資料夾對齊 GitHub，會蓋掉還沒存的資料。
  現在 `windows/run_live.ps1` 看到 `local/state.json` 就會直接跳過。
- 想開機自動啟動：把 `啟動交易猩猩.bat` 的捷徑放到「啟動」資料夾（Win+R 輸入 `shell:startup`）。
